# 株価スクリーニング通知ツール（取引時間中リアルタイム版）

取引時間中(前場9:00-11:30・後場12:30-15:30)に30分おきで自動チェックし、
条件に合う銘柄が出たタイミングでDiscord経由iPhoneに通知します。
銘柄は東証の公式リストから毎回自動取得するので、ウォッチリストの手入力は不要です。

**発注は一切行いません。通知を見て、買うかどうか・いくらで買うかはご自身で判断してください。**

## 何をしてくれるか
1. 東証(JPX)の上場銘柄一覧を自動取得
2. 予算(デフォルト20万円 ÷ 100株単位 = 2,000円以下)で買える銘柄に絞り込み
3. ゴールデンクロス/デッドクロス/RSI/出来高急増を判定
4. 前回すでに通知した銘柄・シグナルは除外し、"新しく該当したものだけ"を通知
5. 平日の取引時間中、30分おきに自動実行

## セットアップ手順

### 1. Discordの準備(iPhoneでも通知を受け取れるようにする)
1. iPhoneにDiscordアプリをインストールし、自分専用のサーバーを1つ作成
2. サーバー設定 → 連携サービス → ウェブフック → 「新しいウェブフック」→ URLをコピー

### 2. GitHubリポジトリを作る
1. https://github.com で無料アカウントを作成(まだの場合)
2. 「New repository」で新しいリポジトリを作成
   - **Public推奨**: GitHub Actionsの実行時間が完全無料・無制限になります
     (Privateだと無料枠が月2,000分までで、30分おき運用だと枠を使い切る可能性があります)
   - 銘柄選定ロジックが外部に見える程度で、口座情報やWebhook URLなど秘密情報は
     後述のSecretsに入れるので、Publicでも個人情報が漏れることはありません
3. このフォルダの中身(screener.py, config.json, requirements.txt, .github フォルダ)を
   そのままアップロード(「Add file → Upload files」でドラッグ&ドロップでOK)

### 3. Webhook URLをSecretsに登録
1. リポジトリの Settings → Secrets and variables → Actions → New repository secret
2. Name: `DISCORD_WEBHOOK_URL`
3. Value: 手順1でコピーしたWebhook URL

### 4. 動作確認
1. リポジトリの「Actions」タブ →「株価スクリーニング通知(取引時間中)」→「Run workflow」で手動実行
2. 数分後、Discordに通知(または該当なしのログ)が出れば成功です

これ以降は平日 9:00〜15:30(JST)の間、30分おきに自動実行されます。

## 重複通知を防ぐ仕組み
1回の取引時間中に同じ銘柄へ何度も同じシグナルで通知しないよう、
その日すでに通知した(銘柄, シグナルの種類)を `state/notified.json` に記録し、
GitHub Actionsのキャッシュ機能で実行間を引き継いでいます。翌営業日になると
日付キーが変わるので自動的にリセットされます。

## 設定を変える場合(config.json)
- `budget_yen`: 使える予算(円)。単元株(100株)ベースで計算されます
- `markets`: 対象市場(デフォルトはプライムとスタンダード)
- `max_notify`: 1回の通知に含める最大銘柄数

## 知っておいてほしいこと
- 30分おき・取引時間中(1日13回)の実行なので、Yahoo Financeへのアクセス頻度が上がります。
  一時的にデータ取得が不安定になることがあります(その回はスキップされるだけで、次回また試みます)
- このツールが拾う銘柄は「テクニカル指標に機械的に該当した」というだけで、
  業績や材料(ニュース)などは一切見ていません。通知が来ても、実際に買うかは必ずご自身で判断・確認してください
- 取引時間中に頻繁にスマホを見られない状況であれば、大引け後1回だけの通知で
  じっくり判断する運用の方が向いている場合もあります(cronを `35 6 * * 1-5` の1行だけに変えれば戻せます)
- 投資は自己責任です。本ツールの通知内容によって生じた損失について責任は負いかねます
